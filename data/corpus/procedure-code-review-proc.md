# Code Review Procedure

**Category:** procedure  
**Company:** Solara Robotics Inc.

A summary of related changes is available in the engineering changelog. This document is maintained by the Operations team and reviewed quarterly.

This policy applies to all Solara Robotics employees, contractors, and interns unless otherwise noted. Every pull request requires approval from at least 2 reviewers before it can be merged. This information is considered internal and should not be shared outside the company.
