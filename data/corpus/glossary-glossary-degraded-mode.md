# Degraded mode

**Category:** glossary  
**Company:** Solara Robotics Inc.

This procedure was last reviewed and updated following the Q2 engineering retrospective. A summary of related changes is available in the engineering changelog.

Exceptions to this guidance require written approval from a department head. Degraded mode is a reduced-capability operating state a unit enters automatically when one or more non-critical sensors fail. This procedure was last reviewed and updated following the Q2 engineering retrospective.
